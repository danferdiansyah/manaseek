# Home service icons

Eight minimalist matte 3D icons, regenerated using the built-in `image_gen` tool. Objects are opaque and softly shaded, with simple silhouettes and restrained green, ivory, and ochre colors. CSS supplies the glass containers.

The 192 × 192 WebP assets retain transparent alpha channels. The shared imports also serve headers, cards, loading states, and navigation across the app.
