# Shared 3D illustrations

Four minimalist matte 3D icons, regenerated with the built-in `image_gen` tool to match the eight service icons. Each is a transparent 192 × 192 WebP image, encoded at quality 88 with alpha quality 100.

- [home.webp](home.webp): navigation / home.
- [ihram.webp](ihram.webp): folded ihram cloth.
- [tawaf.webp](tawaf.webp): Kaaba with a plain non-directional orbit, decorative rather than a ritual movement diagram.
- [notification.webp](notification.webp): notification bell.

See the [current prompt set and full asset inventory](../ICONS.md).
